## Решение пользователя

Пользователь согласовал глубокую адаптацию готовой книги для слушателя. Это отдельная редакция того же произведения, с сохранением содержания, примеров и практических результатов. Самостоятельная новая книга на ту же тему и сокращённый пересказ не заказывались. Запрет дублировать содержание между разными книгами серии не запрещает согласованную аудиоредакцию одной книги.

Для литературной работы пользователь подтвердил Astra High, для завершающей технической сборки — Astra Medium. Перед дальнейшей сменой этапа сообщать рекомендуемый режим. Extra High использовать адресно при конкретной оставшейся трудности. Выбранную настройку сообщает пользователь; ассистент её не переключает и не видит фактического расхода квоты.

## Выходные файлы

Обязательная пара одной редакции:

- `Как-продавать-услуги_Аудиоредакция_Для-чтения.docx` — титул, содержание, номера страниц, библиография и точные английские примеры в приложении.
- `Как-продавать-услуги_Аудиоредакция_Для-Литрес.docx` — тот же текст с оформлением для загрузки **электронного текста** по [требованиям Литрес](20-LITRES-UPLOAD-REQUIREMENTS.md).

Дополнительный рабочий файл `Как-продавать-услуги_Аудиоредакция_Для-озвучки.txt` содержит произносимый текст, включая заголовки, введение, главы и заключение. Титульная реплика называет автора, книгу и серию. Библиография, английское приложение, оглавление, номера страниц и производственные комментарии в TXT не включены.

DOCX для Литрес не является готовым звуковым файлом. Для публикации именно аудиокниги потребуются запись, контроль произношения, проверка звука и отдельный пакет по требованиям аудиопубликации. Авторское утверждение финальной записи, статус ACCEPTED/LOCKED и прохождение модерации не присваиваются автоматически.

Дополнительный запрет слова «опора» и его форм проверяется отдельно. Буквальные длинные повторы проверяются внутри глав и между главами аудиоредакции. ## Воспроизведение сборки

Из каталога `book-1/audio/` выполнить с Python основного runtime:

```bash
python adapt_audio.py
python build_audio_documents.py --output-dir /absolute/output/directory
```

[editorial_edits.py](book-1/audio/editorial_edits.py) хранит авторские изменения, [adapt_audio.py](book-1/audio/adapt_audio.py) — проверяемые преобразования и привязку к исходнику. Подробный `source_map.json` пересоздаётся сборкой; компактный манифест редакции хранится в Git. При изменении исходного печатного текста обновлять привязки осмысленно; не применять идентификаторы абзацев к другому исходнику без проверки.

Перед записью подготовить словарь произношений для выбранного движка или чтеца, проверить имена и цифровые записи на пробном фрагменте, затем прослушать готовые главы. Служебные обозначения пауз и ударений не добавлять в литературный текст автоматически: правила зависят от выбранного способа озвучивания.

Дополнительная проверка русских обозначений: [ACCA, история названия](https://www.accaglobal.com/cis/ru/discover/about/history.html); [Qlean, официальные контакты](https://qlean.ru/contacts). Русское написание иностранных брендов служит произношению; исходные названия и URL остаются в библиографии.
