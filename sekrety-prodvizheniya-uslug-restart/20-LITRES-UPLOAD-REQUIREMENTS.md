# Требования Литрес к файлу книги и изображениям

Проверено: **2026-09-07**. Проект: «Секреты продвижения услуг», книга 1 «Как продавать услуги». Документ добавлен по поручению пользователя. Перед новой публикацией сверять официальные страницы; при изменении правил обновлять этот документ и проверки сборки.

## Файл электронной книги

| Параметр | Условие Литрес |
| --- | --- |
| Форматы | DOCX, FB2, PDF |
| Размер | До 70 MB |
| Объём | От 4000 знаков с пробелами |
| Исключить из рукописи | Титул с автором/названием, содержание, колонтитулы, пагинацию, разрывы страниц, аннотацию, печатные выходные данные |
| Также исключить | Гиперссылки на изображениях, эмодзи, символы ˊˈʻʼˋʹːˌ; коммерческую рекламу и адреса коммерческих сайтов |

Источник: [официальная инструкция](https://selfpub.ru/faq/first-step/), разделы подготовки файла и рекламы.

## Иллюстрации внутри книги

| Параметр | Статус и значение |
| --- | --- |
| Формат, цвет | Требование: PNG/JPG, RGB |
| Площадь | Максимум 2 000 000 пикселей: ширина × высота |
| Длина | Рекомендация: до 1024 px |
| Ширина | Рекомендация: до 900 либо 1024 px |
| Разрешение | Рекомендация: 72 dpi |
| Обтекание | «В тексте» |

Обрабатывать исходник **до вставки**: уменьшение рамки Word не уменьшает встроенный оригинал. Обложка загружается отдельно. Для печати: чёрно-белые иллюстрации, автоматическое уменьшение при превышении 10 × 15 см. [Источник](https://selfpub.ru/faq/first-step/), раздел иллюстраций.

## Подготовка DOCX

DOCX рекомендован самой площадкой. Навигация строится по стилям «Заголовок 1», «Заголовок 2», «Заголовок 3». Заголовки не выделять вручную жирным/курсивом; убрать пустые абзацы после них и пустые заголовки. Параметры печатной страницы не определяют отображение электронной книги.

Таблицы, схемы, уравнения и формулы передавать иллюстрациями. Встраивать файлы изображений, не внешние ссылки. Подпись размещать следующим абзацем. Сноски оформлять штатной функцией Word. [Официальное руководство по Word](https://blog.selfpub.ru/workinword).

## Обложка — отдельный файл

| Параметр | Требование |
| --- | --- |
| Формат, цвет | PNG/JPG, RGB |
| Минимальные размеры | 2400 × 3405 px |
| Пропорции, ширина:высота | От 3:4 до 1:2 |
| Размер файла | Не более 5 МБ |

Источник: [публикация электронной книги](https://selfpub.ru/faq/ebook/), раздел создания обложки. Проверен текст страницы, включая предел 5 МБ. Лимиты внутренних иллюстраций к обложке не применять.

## Принятые настройки и проверки нашего проекта

Это **решения проекта**, а не дополнительные требования площадки:

1. Каждую редакцию выдавать двумя DOCX: для чтения и для Литрес. Читательская версия сохраняет редактируемые таблицы; обе версии имеют одинаковый текст и последовательность глав без деления на части.
2. Загрузочная сборка выбирает PNG/RGB, метку 72 dpi, ширину и высоту не более 1024 px с сохранением пропорций. Это обеспечивает выполнение обеих рекомендаций по сторонам и ограничения площади. Число 300 dpi не использовать как доказательство соответствия.
3. Проверять изображения **внутри сохранённого DOCX**: фактические пиксели, их произведение, формат, цвет, dpi, встраивание и расположение. Не ограничиваться размерами рамки Word или суммарным весом DOCX.
4. Проверять сохранность всех ячеек, чисел и формул; визуально проверять читаемость после преобразования. Если таблица становится нечитаемой, пересобирать её оформление без потери содержания.
5. Сохранять результаты в `litres-audit.json`. Не объявлять успешной конвертацию/модерацию Литрес до фактической проверки на площадке.
