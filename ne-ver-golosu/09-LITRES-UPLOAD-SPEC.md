# «НЕ ВЕРЬ ГОЛОСУ» — ТЕХНИЧЕСКИЙ GATE ЛИТРЕС АВТОРЫ

**Проверено:** 14 августа 2026 года по актуальной справке ЛитРес Авторы / selfpub.ru.

## Основной формат финальной рукописи

**DOCX** — основной upload-ready файл.

ЛитРес Авторы принимает DOCX, FB2 или PDF; для обычной reflowable электронной книги DOCX подходит и не требует ручной сборки FB2.

Официальный источник:
https://selfpub.ru/faq/first-step/

## Ограничения файла

- минимум: 4000 знаков с пробелами;
- максимум: 70 MB;
- шрифт и кегль не являются частью читательского дизайна электронной книги: конечное отображение зависит от устройства и настроек читателя.

## ЧЕГО НЕ ДОЛЖНО БЫТЬ В UPLOAD-DOCX

По официальной справке ЛитРес в текстовом файле должны отсутствовать:

- имя автора;
- название произведения;
- встроенное «Содержание» / оглавление;
- колонтитулы;
- нумерация страниц;
- принудительные разрывы страниц;
- аннотация;
- ISBN, УДК, ББК и другие выходные данные печатного издания;
- изображения с гиперссылками;
- перечисленные ЛитРес нестандартные символы;
- emoji.

**Обложка не вставляется в файл книги** — загружается отдельно в мастере публикации.

## Как размечать структуру

Главы и части размечаются стандартными стилями заголовков Word, чтобы конвертер ЛитРес построил оглавление автоматически.

Для проекта:
- `Heading 1 / Заголовок 1` — части книги, заключение, приложения, примечания;
- `Heading 2 / Заголовок 2` — главы и отдельные приложения;
- обычный текст — `Normal / Обычный`;
- локальные подзаголовки внутри глав — `Heading 3`, только если они действительно нужны смыслу.

Не назначать стиль заголовка пустым строкам и целым обычным абзацам.

## Разрывы

Принудительные page breaks не использовать. Части/главы отделяются стилем заголовка и обычным абзацным интервалом. Электронная книга сама переразбивает страницы на устройстве читателя.

## Иллюстрации

Основная рукопись задумана без обязательных иллюстраций: это снижает риск конвертационных ошибок и не привязывает книгу к быстро устаревающим скриншотам интерфейсов.

Если позже появится действительно необходимая схема:
- PNG/JPG;
- RGB;
- обтекание «в тексте»;
- предварительно подготовленный размер;
- без гиперссылки.

## Ссылки и источники

Книга не должна превращаться в рекламный каталог. ЛитРес отдельно запрещает коммерческую рекламу и ссылки рекламного характера.

Для экспертной проверяемости в рукописи используется раздел **«Примечания и источники»** с названиями организаций, документов, датами и адресами официальных/научных источников как библиографическими данными. Коммерческих призывов и партнёрских ссылок нет.

## Метаданные — ОТДЕЛЬНЫЙ ФАЙЛ

Отдельно от рукописи готовится `LITRES-METADATA.md`, где будут:
- автор: Елена Дым;
- название;
- подзаголовок;
- аннотация;
- жанр/категории-кандидаты;
- ключевые слова;
- возрастная маркировка — после отдельной проверки;
- текст для карточки;
- brief обложки.

В upload-DOCX эти данные не дублируются.

## Обложка

Обложка загружается отдельно. Финальные параметры перед созданием обложки проверяются ещё раз непосредственно по мастеру публикации/справке ЛитРес. В рабочем пакете хранится только brief, пока пользователь не запускает создание финального визуала.

## Финальная техническая QA

Перед передачей DOCX:

- [ ] нет автора/названия/аннотации внутри;
- [ ] нет встроенного TOC;
- [ ] нет page breaks;
- [ ] нет headers/footers/page numbers;
- [ ] все части/главы имеют правильные Heading styles;
- [ ] нет пустых Heading-параграфов;
- [ ] нет emoji и проблемных специальных символов;
- [ ] нет случайных коммерческих ссылок;
- [ ] размер <70 MB;
- [ ] DOCX открывается без repair warning;
- [ ] файл отрендерен и визуально проверен;
- [ ] после загрузки в ЛитРес необходимо просмотреть результат конвертации в их preview до публикации.
