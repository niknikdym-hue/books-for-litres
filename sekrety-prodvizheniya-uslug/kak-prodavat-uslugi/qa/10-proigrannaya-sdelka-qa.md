## 5. Practical value

**PASS.**

Artifact: **Цикл обучения на сделках** (internal ID: Lost-Deal Learning Loop).

Seven fields:
1. outcome/facts;
2. seller explanation marked as hypothesis;
3. buyer feedback/evidence where available;
4. related book-system element only after evidence;
5. signal strength: one case / repeated signal / supported pattern;
6. one bounded change;
7. observable future check.

Practical starting set of 5–10 outcomes is explicitly NOT presented as statistically representative.

The chapter also requires wins and no-decision outcomes, reducing loss-only attribution distortion.
