## 4. Текущий Definition proposal

`BOOK-DEFINITION.md` предлагает стратегический центр:

> продажа профессиональной услуги — работа с неопределённостью покупки: результат, поставщик, доказательства, процесс, цена, границы и следующий шаг должны стать достаточно ясными, чтобы подходящий клиент мог принять решение.

Статус центра: **DRAFT**. AI не присваивает `DEFINITION-APPROVED`.

До прямого принятия пользователем Definition нельзя считать центральное обещание/механизм окончательно закреплёнными.

## 6. Роль старого издания

Старое издание «Как продавать услуги» — **legacy source**, не draft новой книги.

Разрешено извлекать:

- сильные вопросы;
- наблюдения;
- идеи для повторной проверки;
- исторический контекст;
- материал для legacy ledger.

Запрещено:

- брать старое оглавление как основу новой Architecture;
- переписывать старые главы по абзацам;
- сохранять прежнюю последовательность ради преемственности;
- считать старые факты и рекомендации актуальными без проверки;
- использовать старый текст как стилевой эталон;
- сохранять старый материал только потому, что он уже опубликован.

Публичный legacy-фрагмент может использоваться только для category/legacy diagnosis.
