# books-for-litres

Рабочий репозиторий книжных проектов для ЛитРес.

## Активный проект

### Елена Дым — «Не верь голосу»

Рабочая папка: [`ne-ver-golosu/`](./ne-ver-golosu/)

**Подзаголовок:** «Как жить в мире, где голос, лицо и видео больше ничего не доказывают».

Статус: PRE-WRITING / SOURCE-GATED. Концепция, архитектура, источниковый регламент, проверенные кейсы, издательское позиционирование и рабочий процесс подготовлены. Следующая содержательная работа — SOURCE MAP и черновик главы 1 «Голос».

Основные файлы проекта:

- [`00-PROJECT-STATUS.md`](./ne-ver-golosu/00-PROJECT-STATUS.md) — текущий статус и неприкосновенные правила;
- [`01-BOOK-BIBLE.md`](./ne-ver-golosu/01-BOOK-BIBLE.md) — центральная идея, читатель, позиционирование и продукт книги;
- [`02-STRUCTURE-AND-CHAPTER-BRIEFS.md`](./ne-ver-golosu/02-STRUCTURE-AND-CHAPTER-BRIEFS.md) — полная архитектура и брифы глав;
- [`03-SOURCE-GATE.md`](./ne-ver-golosu/03-SOURCE-GATE.md) — правила источников и первичная подтверждённая база;
- [`04-STYLE-FACTCHECK-SAFETY.md`](./ne-ver-golosu/04-STYLE-FACTCHECK-SAFETY.md) — стиль, фактчек и границы безопасного раскрытия темы;
- [`05-CASE-LEDGER.md`](./ne-ver-golosu/05-CASE-LEDGER.md) — реестр проверенных реальных кейсов;
- [`06-LITRES-PACKAGING.md`](./ne-ver-golosu/06-LITRES-PACKAGING.md) — название, аннотация, позиционирование, обложка и семантика карточки;
- [`07-WRITING-WORKFLOW.md`](./ne-ver-golosu/07-WRITING-WORKFLOW.md) — порядок написания и контрольные gates.
