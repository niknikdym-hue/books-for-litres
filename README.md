# books-for-litres

Рабочий репозиторий книжных проектов для ЛитРес.

## Активный проект

### Елена Дым — «Не верь голосу»

Рабочая папка: [`ne-ver-golosu/`](./ne-ver-golosu/)

**Подзаголовок:** «Как жить в мире, где голос, лицо и видео больше ничего не доказывают».

**Статус: READY FOR LITRES UPLOAD — MANUSCRIPT COMPLETE.**

Полная экспертная рукопись написана, источниковый и правовой фактчек проведён, технический DOCX собран под актуальные требования ЛитРес, автоматический QA и полный render-QA пройдены.

Финальный файл для загрузки:

[`ne-ver-golosu/dist/ne-ver-golosu-litres.docx`](./ne-ver-golosu/dist/ne-ver-golosu-litres.docx)

Финальные показатели: **176 392 знака с пробелами, 22 761 слово, 4,41 авторского листа**.

- [`08A-INTERLUDE-RESEARCH-GATES.md`](./ne-ver-golosu/08A-INTERLUDE-RESEARCH-GATES.md) — проверка экспертных интерлюдий;
