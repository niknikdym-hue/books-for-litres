## 6. ВЫБРАННЫЙ КАНДИДАТ: ZONOS2

Официальные проекты:
- `https://github.com/Zyphra/ZONOS2`
- `https://github.com/Zyphra/zonos2.cpp`
- `https://huggingface.co/Zyphra/ZONOS2-GGUF`

Почему выбран:
- новая модель 2026 года;
- более 6 млн часов многоязычной речи в обучении;
- русский официально Tier 2;
- naturalistic/expressive TTS заявлен разработчиком;
- нативный C++/GGUF inference;
- без Python/PyTorch на инференсе;
- официальный macOS arm64 / Metal prebuilt;
- локально, без обязательного cloud API;
- лицензии официальных компонентов permissive: основной ZONOS2 repo указывает MIT, GGUF model card — Apache-2.0;
- есть plain TTS без обязательного voice cloning.

### Важный M1 / 8 GB gate

Текущий минимальный официальный GGUF в `main`:
- `zonos2-q4_k.gguf` — 4.92 GB;
- `dac.gguf` — 254 MB.

`spk-encoder.gguf` для первого plain-TTS теста не нужен.

Ранее публиковался `q2_k-experts` ~2.87 GB, но он удалён из текущего official main. Старый удалённый артефакт **не использовать**.

Разработчики показывают, что Metal inference memory-bandwidth limited; измеренный M3 base уже не быстрый. Поэтому M1 / 8 GB пока не считается доказанно подходящим.

Правильный статус:

**ZONOS2 = GO FOR ONE SHORT TEST ONLY; M1/8GB = UNPROVEN UNTIL REAL LOAD.**

Если модель не помещается, вызывает тяжёлую memory pressure/swap или требует каскада нестандартных патчей — закрыть этот путь без многочасового ремонта.
