## 5. ПРАВИЛО ДЛЯ СЛЕДУЮЩЕГО ДВИЖКА

После неудачных попыток вводится жёсткий gate ДО установки.

### Сначала исследование, потом установка

Перед тем как просить пользователя что-либо скачать или запускать:

1. Веб-проверить актуальные на текущую дату варианты.
2. Использовать первичные источники: официальный GitHub, официальную документацию, model card, paper/license.
3. Подтвердить:
   - русский язык;
   - естественность/просодию, ориентированную на human-like speech;
   - Mac Apple Silicon compatibility;
   - M1 / 8 GB реалистичность;
   - размер модели и RAM/дисковые требования;
   - лицензию и коммерческое использование;
   - отсутствие обязательного API / биллинга;
   - реальный путь запуска на macOS.
4. Проверить актуальные issues именно по macOS/MPS и по русскому, чтобы не повторить Chatterbox.
5. Не выбирать модель только потому, что она «open source» или «поддерживает русский».
6. Ключевой критерий: пользователь должен услышать живой русский голос без ощущения «авточтеца».

### Установка только после предварительного GO

Не делать длинную установку ради слепой проверки.

Идеальный следующий кандидат должен иметь:
- простой локальный запуск;
- короткий реальный русский демо-тест;
- желательно готовый русский диктор или действительно сильную multilingual prosody;
- минимум ручной SSML/пауза-разметки.

Если первый SHORT TEST звучит роботизированно — сразу закрыть движок, не чинить его часами.
