## 5. Точная ошибка Chatterbox, на которой остановились

При загрузке модели возникает:

`TypeError: 'NoneType' object is not callable`

Точное место:
`self.watermarker = perth.PerthImplicitWatermarker()`

То есть ошибка происходит в библиотеке водяного знака Perth до генерации звука.

Сначала MPS-путь падает на этом, затем CPU fallback падает на том же самом.

Это НЕ доказательство плохой работы самой TTS-модели и НЕ ошибка скачанной модели.

В официальном GitHub Chatterbox есть открытый PR #469 с тем же дефектом: если `PerthImplicitWatermarker` отсутствует / не callable, предлагается fallback на `DummyWatermarker`. Есть также issue Perth #7 про проблемы импорта / `pkg_resources` / `setuptools`.

Последняя предложенная, но ЕЩЁ НЕ ВЫПОЛНЕННАЯ пользователем команда была downgrade setuptools до 80.9.0:

`"/Users/elenadymova/Documents/New project/audiobook-tts-m1-codex-kit/chatterbox-v3-test/.venv/bin/python" -m pip install "setuptools==80.9.0"`

ВАЖНО: после раздражения пользователя эту команду НЕ считать выполненной. Не заставлять пользователя снова идти по цепочке команд без необходимости.
