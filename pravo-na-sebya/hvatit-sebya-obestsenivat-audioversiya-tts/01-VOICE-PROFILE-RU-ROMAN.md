# Голосовой профиль — серия «Право на себя»

Книга: «Хватит себя обесценивать»
Автор: Елена Дилон
Основной голос: Silero `ru_roman`
Статус: голос утверждён пользователем для дальнейшей работы.

## Базовые параметры

- Model family: Silero V5 CIS Base No Stress
- Model id: `v5_cis_base_nostress`
- Language: `ru`
- Speaker: `ru_roman`
- Sample rate: 48000 Hz
- Основная задача: спокойное, ясное, взрослое чтение психологического нон-фикшна без дикторского пафоса и без рекламной подачи.

## Манера чтения

Нужно стремиться к:
- естественной разговорно-книжной интонации;
- спокойной уверенности;
- отсутствию театральности;
- отсутствию чрезмерной «мотивационной» подачи;
- смысловому выделению, а не механическим акцентам;
- достаточному воздуху между смысловыми блоками;
- устойчивому темпу при длительном прослушивании.

## Что уже известно

Пользователь голос принимает.
Основные зоны дальнейшей настройки:
- ударения;
- интонация;
- паузы;
- ритм длинных предложений.

## Базовые паузы runner

Текущая отправная точка:
- sentence pause: 300 ms
- paragraph pause: 620 ms
- heading pause: 900 ms
- chapter end pause: 1200 ms

Эти значения не считаются окончательными. Они корректируются только после короткого и длинного тестового прослушивания.

## Правила ударений

1. Автоматическая постановка — Silero Stress.
2. Ошибки и неоднозначности — ручной словарь `tts-overrides.json`.
3. Не размечать ударение вручную во всём исходном тексте.
4. Исходный литературный TXT не менять.
5. После обнаружения ошибки в повторяющемся слове исправлять её централизованно в словаре, а не локально во всех главах.

## Серийная идентичность

Если после длинного теста профиль будет окончательно принят, этот голосовой профиль становится стандартом первой книги и отправной точкой для остальных книг серии «Право на себя».

## Музыка

По умолчанию речь идёт без музыкальной подложки.
Допускается короткая фирменная тема в начале и/или конце книги после отдельного теста. Музыка не должна перекрывать речь и не должна навязывать эмоциональную интерпретацию текста.

## Контроль качества

Субъективное качество тембра и интонации оценивает пользователь прослушиванием. Машинный контроль используется для технических параметров, структуры и целостности файлов.
