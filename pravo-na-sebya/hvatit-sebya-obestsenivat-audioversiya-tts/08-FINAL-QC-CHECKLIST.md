# FINAL QC CHECKLIST — аудиокнига «Хватит себя обесценивать»

Использовать только после утверждения короткого и длинного тестов.

## A. Полнота

- [ ] 17 речевых треков присутствуют.
- [ ] Порядок соответствует `03-TRACK-MAP.md`.
- [ ] Нет пропущенных абзацев.
- [ ] Нет повторённых фрагментов.
- [ ] Нет случайно озвученных служебных строк.
- [ ] Исходник соответствует locked SHA, либо обновление источника отдельно зафиксировано.

## B. Произношение

- [ ] «Елена Дилон» произносится одинаково во всех местах.
- [ ] Название книги произносится одинаково.
- [ ] Название серии произносится одинаково.
- [ ] Все найденные ошибочные ударения внесены в `tts-overrides.json`.
- [ ] Повторяющиеся слова не имеют разных вариантов ударения без смысловой причины.

## C. Режиссура

- [ ] Нет одинаково тяжёлой паузы после каждого короткого абзаца.
- [ ] Заголовки отделены, но не декламируются.
- [ ] Внутренняя речь не превращена в актёрские роли.
- [ ] Ирония не переиграна.
- [ ] Длинные предложения не разорваны в случайном месте.
- [ ] Вопросительные серии звучат как связная мысль, а не анкета.
- [ ] Темп стабилен при длительном прослушивании.
- [ ] Нет ощущения «мотивационного ролика» или «психотерапевтического шёпота».

## D. Монтаж

- [ ] Нет обрезанных согласных в начале/конце вставок.
- [ ] Нет щелчков на стыках.
- [ ] Нет внезапной смены громкости.
- [ ] Нет внезапной смены тембра между перегенерированными фрагментами.
- [ ] Тишина в начале/конце треков единообразна.
- [ ] Между главами нет лишней искусственной тишины.

## E. Технический мастер

- [ ] Сохранены финальные MASTER WAV.
- [ ] MASTER не подвергался лишнему lossy-пережатию.
- [ ] Нет clipping.
- [ ] Нет NaN/повреждённых файлов.
- [ ] Частота дискретизации и канальность единообразны во всех мастерах.
- [ ] Измерена и выровнена воспринимаемая громкость.

## F. Музыка

Если используется:
- [ ] Только утверждённая музыка пользователя.
- [ ] Нет постоянной подложки под основной текст.
- [ ] Музыка не перекрывает слова.
- [ ] Использованные файлы перечислены в финальном манифесте.
- [ ] Intro/outro не создают скачка громкости относительно речи.

Если музыка не улучшает результат:
- [ ] Книга выпускается без музыки.

## G. Слуховой контроль

Обязательно полностью прослушать:
- [ ] титульный трек;
- [ ] вступление;
- [ ] начало и конец каждой главы;
- [ ] все места, которые перегенерировались;
- [ ] главу с большим количеством коротких абзацев;
- [ ] главу с деньгами/ценами;
- [ ] заключение;
- [ ] минимум один непрерывный фрагмент 20–30 минут для проверки утомляемости.

## H. ЛитРес gate

Непосредственно перед финальным экспортом:
- [ ] заново открыть официальные актуальные требования ЛитРес Авторы;
- [ ] проверить формат;
- [ ] битрейт;
- [ ] канальность;
- [ ] ограничения по размеру и длительности файла;
- [ ] требования к порядку глав;
- [ ] требования к обложке;
- [ ] правила/маркировку синтетической или AI-озвучки, если они действуют на дату загрузки.

Только после этого собирать `LITRES/` пакет.

## Финальные статусы

`MASTER PASS` — фонограмма технически и редакционно готова.

`LITRES PASS` — финальный экспорт проверен по актуальным требованиям площадки.
