## Gate загрузки модели

Сначала сделать минимальную проверку, что официальный `zonos2-cli` запускается на arm64/Metal.

Затем попытаться синтезировать **только `15A-ZONOS2-SHORT-TEST-NARRATION.txt`**.

Условия первого запуска:
- Metal/GPU;
- Q4_K;
- DAC;
- plain TTS;
- без speaker embedding;
- без voice cloning;
- без emotion directions;
- без SSML;
- без русского Python text normalizer;
- raw UTF-8 text path;
- фиксированный seed, чтобы результат был воспроизводим.

Если есть выбор параметров, сначала использовать максимально близкие к официальным default значения. Не начинать tuning до пользовательского прослушивания.

## Немедленный STOP

Остановиться без попыток «починить всё на свете», если:
- binary не запускается на M1;
- модель не помещается в память разумно;
- начинается тяжёлая memory pressure / swap и система становится непрактичной;
- происходит crash/Metal error, требующий нестандартной сборки или каскада патчей;
- первый WAV не получается простым штатным путём.

Разрешена максимум одна очевидная корректировка запуска по официальной документации. После этого — STOP и отчёт.

## После генерации

Codex не должен сам объявлять голос качественным.

`TECHNICAL SHORT TEST: GENERATED`

Дальше пользователь слушает файл.

Только пользователь выставляет:
- `HUMAN READING: PASS`;
- или `HUMAN READING: FAIL`.

При FAIL ZONOS2 закрывается без LONG TEST.
