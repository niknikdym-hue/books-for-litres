## Почему выбран ZONOS2

Официальный ZONOS2 — новая модель Zyphra 2026 года, обученная на более чем 6 млн часов многоязычной речи. Русский язык официально указан как Tier 2. Заявлены naturalistic voice cloning, выразительность и управление просодией.

Для Apple Silicon есть отдельный официальный `zonos2.cpp` — нативный C++/GGUF-порт без Python и PyTorch на инференсе. В актуальном релизе есть готовые macOS arm64 / Metal binaries и отдельное native-приложение.

Ключевое для нашего проекта:
- локальный запуск;
- API и облачный биллинг не обязательны;
- macOS arm64 / Metal официально поддержан;
- можно получить WAV напрямую;
- русский официально поддержан;
- в официальных лицензиях нет non-commercial ограничения: основной репозиторий ZONOS2 указывает MIT, GGUF model card — Apache-2.0; обе лицензии разрешительные;
- не требуется повторять прежний Qwen voice-cloning pipeline;
- не требуется чинить Chatterbox/Python-цепочки.

Официальные источники:
- https://github.com/Zyphra/ZONOS2

## Жёсткое ограничение M1 / 8 GB

Это пока НЕ аппаратный PASS.

Текущий минимальный официальный GGUF в `main`:
- `zonos2-q4_k.gguf` — 4.92 GB;
- `dac.gguf` — 254 MB;
- `spk-encoder.gguf` — 24.3 MB, для первого plain-TTS теста не нужен.

Ранее существовал более лёгкий `zonos2-q2_k-experts.gguf` (~2.87 GB), однако он удалён из актуального official main. Старый удалённый артефакт для проекта не использовать.

Разработчики показывают, что Metal-инференс ограничен пропускной способностью памяти; даже измеренный M3 base не является быстрым. Поэтому для MacBook Air M1 / 8 GB корректный статус только такой:

**Q4_K реалистичен для попытки одного короткого теста, но работа на M1 / 8 GB ещё не доказана.**

Если модель не загружается, возникает тяжёлая memory pressure/swap или первый короткий WAV генерируется непрактично долго — ZONOS2 закрывается для этого Mac без длинного цикла оптимизаций.

Качество Q4_K по опубликованным метрикам близко к F16, но эти метрики получены на английском наборе. Они не доказывают качество русского — поэтому HUMAN READING GATE обязателен.

## Shortlist после жёсткого отсева

### 1. ZONOS2 / zonos2.cpp — SELECTED / SHORT TEST GO

Лучшее сочетание свежести модели, официального русского, permissive licensing и действительно нативного Apple Silicon пути.

### 2. Qwen3-TTS 0.6B CustomVoice — HOLD

Плюсы: Apache-2.0, русский, компактнее ZONOS2, управляемая речь.

Почему не первый выбор:
- у официального проекта есть свежие сообщения о проблемах с русскими ударениями;
- Apple-Silicon/MPS поддержка в upstream всё ещё дорабатывается;
- штатные CustomVoice speakers не являются нативными русскими дикторами;
- предыдущий Qwen cloning path в этом проекте уже закрыт как FAIL. Новый CustomVoice-путь технически другой, но возвращаться к Qwen первым кандидатом сейчас нет основания.

### 3. Bark — BACKUP ONLY

MIT, русский и Apple Silicon возможны, но модель заметно старее, менее предсказуема по точному следованию тексту и хуже подходит для стабильного длинного книжного чтения.

## Первый тест ZONOS2

Первый тест делаем **без voice cloning**. Сначала проверяем базовую способность модели говорить по-русски естественно. Это исключает ещё одну переменную и не повторяет неудачный Qwen cloning experiment.

Для первого теста:
- только актуальный официальный release `zonos2.cpp v0.5.1`;
- только macOS arm64 Metal build;
- только актуальный `Q4_K`;
- plain TTS;
- text normalization OFF / raw UTF-8 path, потому что отдельного русского NeMo-normalizer в нативном C++ пути нет;
- тестовый текст без цифр, дат и сложных сокращений;
- 1 основной WAV + при успешной генерации 1 мини-WAV на титульную строку/ударение автора;
- никаких SSML и ручной ритмической разметки на первом проходе.

Если основной WAV звучит как авточтец — `FAIL / CLOSED`, без долгих попыток «дотянуть» движок настройками.
