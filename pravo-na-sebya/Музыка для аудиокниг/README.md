# Музыка и звуки для аудиокниг

Рабочая папка для музыкальных и звуковых материалов серии «Право на себя» и других аудиокниг проекта.

## Права

Все музыка и звуки в этой папке принадлежат владельцу проекта и разрешены к коммерческому использованию в аудиокнигах.

## Структура

- `Музыка/` — заставки, финальные темы, переходы и другие музыкальные фрагменты;
- `Звуки/` — звуковые эффекты и атмосферные элементы.

Музыка и звуки не добавляются автоматически: каждый элемент используется только если он действительно улучшает восприятие книги, не мешает речи и соответствует общей режиссуре аудиоиздания.
