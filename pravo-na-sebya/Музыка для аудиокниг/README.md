# Музыка и звуки для аудиокниг

Рабочая папка для музыкальных и звуковых материалов серии «Право на себя» и других аудиокниг проекта.

Структура:

- `Музыка/` — заставки, финальные темы, переходы и другие музыкальные фрагменты;
- `Звуки/` — звуковые эффекты и атмосферные элементы.

Используем только материалы, для которых подтверждены права на коммерческое использование в аудиокнигах.

Музыка и звуки не добавляются автоматически: каждый элемент используется только если он действительно улучшает восприятие книги и не мешает речи.
