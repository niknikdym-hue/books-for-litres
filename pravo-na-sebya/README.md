# Серия «Право на себя»

Рабочая папка серии книг Елены Дилон «Право на себя».

## С чего начинать работу

Главный series-level authority:

`SERIES-BRAIN.md`

Он хранит канонический состав серии, порядок книг, тематические границы, общие литературные правила, anti-junk/negative-first запреты и производственный порядок для книг 2–10.

Перед созданием или редактированием любой новой книги серии сначала прочитать актуальный `SERIES-BRAIN.md`, затем book-level authority конкретной книги.

В отдельных папках хранятся рукописи, handoff/authority-файлы, служебные материалы и финальные публикационные/аудиопроизводственные версии конкретных книг.
